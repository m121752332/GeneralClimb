## 1. 遊戲概述

穿紅衣的攀爬者徒手從 101 的 1 樓爬到塔尖，遇到強風、下雨、老鷹就要停下來抓牢；一失手就回 1 樓重來。

**設計支柱**
1. **走或停**：唯一的技巧是判斷何時該爬、何時該放開抓牢；不跳躍、不射擊
2. **看得見的恐懼**：角色表情與動作隨風險值變化
3. **一次一個危機**：同時只有一個事件，失敗永遠是自己的判斷錯誤
4. **登頂有重量**：墜落回 1F、無中繼點，破關動畫是真正的獎勵

| 項目 | 內容 |
| --- | --- |
| 類型 | 2D 垂直攀爬動作，類魂斗羅 16-bit 像素風 |
| 平台 | 手機與電腦瀏覽器（GitHub Pages）；原生 App 後期再定 |
| 引擎 | Cocos Creator 3.8 LTS + TypeScript |
| 畫面 | 直向 9:16，設計解析度 720 × 1280 |
| 一局長度 | 每關約 1–2 分鐘（M2 實測校正）；練習模式約 1 分鐘 |

## 2. 核心循環

1. 開場插畫 → 主畫面（Google 登入 / 開始遊戲 / 練習模式）
2. 開始遊戲：從第 1 關（1F）開始攀爬
3. 攀爬中出現危機（事件預警 1 秒或貼邊）→ 停下抓牢就安全；沒停就累積風險值
4. 風險滿 100 → 墜落 → 結算 → 回 1F 從第 1 關重來，計時歸零
5. 抵達本關平台 → 上捲過場 → 下一關；第 13–14 關為尖塔爬梯
6. 第 14 關觸及塔尖 → 破關動畫 → 記錄成績 → 回主畫面

## 3. 角色與操作

一次爬一格，每格 0.35 秒；放開方向鍵後 0.1 秒內進入「抓牢」。

| 狀態 | 進入條件 | 動畫 | 可否移動 |
| --- | --- | --- | --- |
| 攀爬 | 有方向輸入 | 手腳交替，4 幀循環 | 是 |
| 抓牢（隱身） | 無輸入 0.1 秒 | 四肢貼牆、低頭，輕微半透明 | 按下即回攀爬 |
| 緊張 | 風險 40–69 | 發抖、冒汗、偶爾抱緊牆 | 是 |
| 危機 | 風險 70–99 | 單手懸掛、腳滑、驚恐 | 是，輸入延遲 0.15 秒 |
| 墜落 | 風險 100 或踏出墜落線 | 失手後仰往下掉 | 否 |
| 爬梯 | 第 13–14 關 | 垂直爬梯循環 | 只能上下 |
| 平台站立 | 到達關卡終點 | 站立、喘氣、擦汗 | 否（過場中） |

| 裝置 | 移動 | 抓牢 | 暫停 |
| --- | --- | --- | --- |
| 鍵盤 | 方向鍵 / WASD | 不按 | Esc |
| 手機 | 左下虛擬搖桿（八方向，死區 20%） | 手指離開 | 右上暫停鍵 |
| 手把 | 左類比 / 十字鍵 | 放開 | Start |

斜向輸入一次只移動一個方向，垂直優先。

## 4. 牆面格線與風險區

每樓 12 列、每格 0.35 秒，一關 8 樓約 96 列，純攀爬約 34 秒；加上停下等風、雨，一關約 1–2 分鐘。

| 安全區寬度 | 總欄數 | 安全欄 | 危險欄（每側） | 適用關卡 |
| --- | --- | --- | --- | --- |
| 寬 | 11 | 7 | 2 | 1–2 |
| 中 | 9 | 5 | 2 | 3–6 |
| 中窄 | 7 | 3 | 2 | 7–8 |
| 窄 | 5 | 3 | 1 | 9–11 |
| 很窄 | 5 | 1 | 2 | 12 |
| 爬梯 | 1 | 1 | 0 | 13–14 |

踏出最外側危險欄即墜落。

**竹節外斜**：第 4–11 關每節最上方 24 列兩側各多 1 個危險欄；下一節一開始又縮回。

**障礙物**：部分格子不可抓（清潔機軌道、出風口、裝飾板），逼玩家左右繞開。每 12 列至少 1 個，後段增加到 3 個，且保證有一條不經過危險欄的路。

## 5. 事件排程器（EventScheduler）

| 事件 | 第一次 | 之後間隔 | 持續 | 到期時遇到其他事件 |
| --- | --- | --- | --- | --- |
| 強風 | 第 60 秒判定 | 每 60 秒判定，機率依關卡 | 10–20 秒 | 該次跳過 |
| 下雨 | 第 600 秒 | 每 600 秒 | 20–30 秒 | 排隊，前一個結束 + 4 秒 |
| 老鷹 | 第 300 秒 | 每 600 秒 | 3 秒 | 排隊，前一個結束 + 4 秒 |

狀態：`Idle` → `Warning`（左上圖示 1 秒）→ `Active` → `Cooldown`（4 秒）→ `Idle`。只有 `Idle` 可進入 `Warning`。

老鷹（2026-11-14 修訂）：3D 原創展翅老鷹（`climb/EagleShape.ts`、`scenes/Eagle3D.ts`），警告時從側面盤旋飛近，進行中在攀爬者前上方盤旋。老鷹在場時只要一移動就被發現（2026-11-14 第二次修訂）：紅眼鎖定（眼睛發紅光＋畫面紅閃＋尖嘯）`spotSec` 秒（練習模式 ÷ intensity），接著朝玩家當下那一格俯衝（`diveSec`，翅膀上舉成 V、爪子前伸）；一被盯上停下也來不及，警告那 1 秒就要放手抓牢；落點時玩家在 `hitCols` 欄、`hitRows` 列內（含相鄰一欄的擦身）→ 撲落、回 1F（練習模式回平房地面重練）；已閃到更遠就撲空，老鷹拉起 `diveSec` 秒後才會再盯人。數值在 `levels.json` 的 `events.eagle`。

```ts
// 每幀由 ClimbScene 呼叫，dt 只在攀爬中傳入
update(dt: number) {
  this.clock += dt;
  this.tickState(dt);              // Warning / Active / Cooldown 倒數
  if (this.state !== 'Idle') return;
  const due = this.queue.shift()   // 先處理排隊中的雨、鷹
    ?? this.pollTimers();          // 再看本幀是否到期
  if (due) this.startWarning(due);
}
// 非 Idle 時到期：雨、鷹 push 進 queue；風的判定直接丟棄
```

機率與持續時間用本局種子亂數，種子記在成績裡。

## 6. 畫面與 HUD

直向 720 × 1280，角色固定在畫面下方約 60% 高度，鏡頭平滑跟隨。

| 位置 | 元素 | 說明 |
| --- | --- | --- |
| 左上 | 事件圖示 | 前 1 秒閃爍出現，事件期間顯示剩餘時間條 |
| 左側 | 風險量表 | 直向 0–100；40 / 70 刻度；綠 → 黃 → 紅 |
| 上方中央 | 目前樓層 | 例「47F」；關卡開始顯示「第 6 關 43–50F」 |
| 右上 | 時間、暫停 | 只算攀爬時間 |
| 角色頭頂 | 玩家名稱 | 未登入「霍將軍」 |
| 左下 | 虛擬搖桿 | 觸控裝置才顯示 |
| 邊緣 | 危機紅暈 | 風險 ≥ 40 淡紅，≥ 70 閃爍 |

**螢幕適配**：比 9:16 更長的螢幕固定寬度（上下多露出畫面），更寬的螢幕固定高度（左右多露出畫面）；HUD 貼齊可視範圍邊緣。

**引擎設定**：功能裁剪只保留 2D、UI、Graphics、Mask、動畫、Tween、音效、2D 粒子、Profiler；像素貼圖 Filter Mode 用 Nearest。

設定頁：音量、震動、閃光效果開關、搖桿大小。

## 7. 各畫面流程

| 畫面 | 內容 | 長度 | 可跳過 |
| --- | --- | --- | --- |
| 開場 | 原創插畫：紅衣攀爬者背影 + 101 天際線 | 3 秒 | 是 |
| 主畫面 | 標題、Google 登入、開始遊戲、練習模式、設定、最佳紀錄 | — | — |
| 開始遊戲過場 | 鏡頭拉近 101 底部 | 2 秒 | 是 |
| 練習模式 | 三層樓平房；風、雨、老鷹各低強度一次；不計紀錄 | 約 1 分鐘 | — |
| 上捲過場 | 平台上鏡頭上捲，顯示「第 n 關 · 樓層」 | 1.5 秒 | 否 |
| 墜落 | 凍結 0.3 秒 → 下墜，樓層數字倒數回 1F | 2.5 秒 | 否 |
| 結算 | 最高樓層、墜落原因、歷史最佳；再爬一次 / 回主畫面 | — | — |
| 破關 | 觸及塔尖 → 環顧城市 → 揮手 → 總時間、墜落次數 | 約 15 秒 | 第二次起可 |

墜落原因文案：「太靠邊了…」「風大時要抓牢」「雨天手滑了」「被老鷹撲下來了」。

## 8. 資料設計

- 數值：`config/levels.json`（Cocos 專案內為 `assets/resources/config/levels.json`）
- Firestore：

| 集合 / 文件 | 欄位 | 說明 |
| --- | --- | --- |
| `players/{uid}` | displayName、nameEdited、createdAt | 不存 Email |
| `players/{uid}/runs/{runId}` | seed、maxFloor、cleared、climbMs、fallCause、levelSplitsMs[]、endedAt | 每局一筆 |
| `best/{uid}` | displayName、maxFloor、bestClearMs、updatedAt | 第二版排行榜查這裡 |

`maxFloor` 以 102 代表塔尖。未登入時同樣的 best 結構存 localStorage。安全規則見 `config/firestore.rules`。
